利用規約・プライバシー方針への同意

マイポータルをご利用いただくには、以下の利用規約への同意が必要です。

apps 第1条（本アプリについて）

「マイポータル」は、利用者の Google アカウント（Gmail、Google カレンダー、Google Tasks）および個人用ブックマークを統合管理するためのパーソナルポータル Web アプリケーションです。本アプリは Google Apps Script (GAS) 環境上で動作します。

database 第2条（保存および保持するデータについて）

本アプリでは、利便性とセキュリティを両立するため、以下の場所およびデータのみを安全に保持・管理します：

1. Google スプレッドシート（専用保存領域）:
  • ユーザー設定（テーマ色、ダークモード選択状態、利用規約同意フラグ・日時）
  • ブックマーク一覧（タイトル、URL、表示順序）
  • 利用規約同意一覧（__TERMS__ シート）
  • 操作ログ（操作日時、実行アカウント、操作内容および詳細パラメータ）を __LOG__ シートに自動記録します。
2. ブラウザローカルストレージ (LocalStorage):
  • 画面テーマおよびカラーモード設定の高速初期復元用データ
3. Google 連携データ (Gmail / カレンダー / Tasks):
  • Google 公式 API 経由で直接読み書きされます。外部の第三者サーバー等へ送信・蓄積されることは一切ありません。

security 第3条（個人情報の保護とセキュリティ）

取得および表示されるすべてのデータ（メール、予定、タスク、ブックマーク等）は、利用者自身の Google アカウント権限領域および紐付けられたスプレッドシート内のみで保護されます。

gavel 第4条（免責事項）

本アプリは利用者の生産性向上のために提供されます。Google 側の通信障害や仕様変更により、一時的に同期・表示が制限される場合があります。

lock

Webアプリへのアクセスが制限されています

利用規約に同意いただけない場合は、マイポータルの全機能（Gmail・カレンダー・タスク・ブックマーク等）をご利用いただくことができません。

ご利用を終了する場合は、このブラウザのタブまたはウィンドウを閉じてください。
